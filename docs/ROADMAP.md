## 现在还不能卸灵枢 / Engram

差两个硬条件：

1. **自动提取** —— 外置大脑还是 explicit，主人不说「记住」它就不记。灵枢和 Engram 是**自动摄取**。卸了 = 停止记录新东西。
2. **观察期** —— 迁进来的 205 条要实际用几轮，看检索准不准。搬过来 ≠ 用得好。
   **数据管道已经通了（M4.5），但样本还少，现在下结论就是拿偶然当规律。**

数据上还有个缺口：Engram 的 **105 个实体**和 **7 条关系边**（含 `contradicts` 矛盾关系）没迁——我们暂时表达不了实体和矛盾。

### ~~第二优先~~ ✅ Phase 1 已完成：自动提取（2026-10-30 夜）

**Phase 1（规则型）已交付**：`apps/brain-tools/auto-extract.js` + 接线 + `tests/m5/auto-extract/`（23 条）。
四道闸（疑问/假设/转述/否定/反讽 + 内容闸）先于四条规则（记住 / 以后都·统一用 / 改成·定下来 / 我的+是·用）。
配额硬限每轮 1 / 每会话每天 5 / 全局每天 20；写库 `sourceType=observation` + summary 标「（自动提取）」；
同 content 去重；只在 `turn/end reason=completed` 之后跑；失败静默；可 `config.autoExtract=false` 或
`BRAIN_AUTO_EXTRACT=off` 关闭。契约见 `CONTRACTS.md` §20。

**实测（四个回合全链路真跑，临时库）**：只有「记住：以后都用 pnpm」那个回合被提取成 1 条 observation，
疑问句、假设句、中断回合全部不命中——这就是「宁可漏」的样子。

**Phase 2（模型语义提取）的前置**：观察期数据够（≥20 次检索 + 引用率有基线）、
且必须先有配额与人工抽检办法。**不调模型**这条在 Phase 1 是有意的（Brain 自身不发 LLM 请求）。

原设计要点（仍在约束 Phase 2）：

这是 M5 的核心，也是风险最高的一块。设计要点：

- **跑在 `turn/end` 之后**，不在对话中途（不阻塞、不打断）
- **只提取「主人明确表露的稳定信息」**：偏好、决定、事实、承诺。**不做主观推断**（推断进记忆会污染）
- **写入用 `sourceType: 'observation'` 而不是 `owner_words`**，置信度居中，让主人能区分「我看到的」和「我猜的」
- **必须有配额和开关**：每轮最多 N 条、每天上限、随时可关
- **不自动晋升永久记忆**：长期记忆可以自动进，永久记忆必须主人说了算
- **失败静默**：提取失败不能影响对话，也不能重试到爆炸

**为什么风险高**：自动提取质量差会污染记忆库，而污染比没有更糟——检索会变差，主人会开始不信它。
所以这块必须先做小范围试跑 + 人工抽检，**而且要用 M4.5 的使用统计去量它有没有把检索质量拉低**。

## 明确不做的事

- **不自动开 automatic 注入** —— 它会在每轮对话里塞东西。生产环境的插件组合、真实语料都没验过。
  explicit 已经够用，等统计数据说话再决定。
- **不为了「更聪明」去调检索权重** —— 已实测：ngram 权重一进排序，P@10 就从 83.6% 掉到 49.9%。没有新数据前不动。
- **不迁灵枢** —— 33 个节点全是对话原文，迁进来只是稀释检索。它的价值在自动注入机制，不在数据。
- **不在观察期没跑够之前做自动提取** —— 会把「检索本来就不准」和「自动提取污染了库」两件事混在一起，事后分不清。

## 现在要做的唯一一步

**把它用起来，让样本长到 20 次以上。** 2026-10-29 夜实测：7 天窗口内只有 **1 次**检索。
重启、三页验收、真机链路都早已通过（M4.5 / M6 都验过）——卡着观察期的**不是功能，是使用**。

具体做法（不是加功能，是改用法）：

1. 会话里碰到「之前 / 上次 / 你还记得 / 继续推进」这类指向前史的话，**第一动作就是 `brain_search`**，
   哪怕猜它没记过——零命中本身就是数据；
2. 每做完一件有结论的事，判断值不值得 `brain_remember`（决定 / 踩坑 / 口径），值得就记；
3. 每隔几天跑 `node tools/verify-usage.mjs`，只看四个数：**命中率、零命中榜、弱路降级、覆盖率**；
4. **样本 < 20 次不做任何「准不准」的判断**——包括不用它去决定要不要上自动提取。
