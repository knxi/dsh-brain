## 5. 已知边界（不算缺陷，但要说明）

- **纯同义词 / 纯口语查询**：当前是 FTS（char-space + trigram + ngram），不做语义扩展。
  「保温棉」查不到「岩棉」、「门口那道槛」查不到「踢脚线」——这类只能靠向量检索或查询改写解决，
  不是调权重能解决的。用例 F26 就是刻意留在这个边界上的。
- **任务快照续接**：`task_snapshots` 表是空的，快照未接进生产。
  本报告第 2 节的 `task_resume` 类只覆盖「检索层能否找回未完成任务」，
  **不覆盖「重启后从快照继续」**——那需要先实现快照写入。
